# Collins Atuanya — Student Portfolio

A responsive student portfolio and academic planner for the CSC 106 practical term project at MIVA Open University.

## Live links

- Website: <https://catuanya.github.io/collins-atuanya-csc106-portfolio/>
- Repository: <https://github.com/Catuanya/collins-atuanya-csc106-portfolio>

## Pages

- **Home:** introduction, student profile, and navigation to the portfolio sections.
- **About:** study background, aspirations, skills, a course table, interests, and an HTML video element.
- **Projects:** three illustrated educational project concepts.
- **Planner:** add, complete, and delete study tasks; tasks persist in this browser with local storage.
- **Contact:** validates required fields, email format, and digits-only phone numbers before preparing a message in the visitor's email app. No contact data is sent to or stored by the website.

## Run locally

Open `index.html` in a browser. The site has no build step or external JavaScript dependencies. Google Fonts and the sample nature video use external resources; locally stored SVG illustrations remain available offline.

## Personalise before submission

- Replace `assets/portrait.svg` with a personal photograph and update the alternative text on `index.html` and `about.html`.
- Review the sample project descriptions and contact details.

## Deployment

GitHub Pages is enabled for the `main` branch at the repository root. New commits are deployed automatically; the site entry point is `index.html`.
